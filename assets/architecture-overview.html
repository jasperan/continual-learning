Continual Learning SLM

architecture & strategy overview — Qwen2.5-1.5B real-time knowledge internalization

Five complementary strategies that let Small Language Models learn from new documents at inference time without catastrophic forgetting. From direct weight modification to zero-update agentic loops.

1 — DualMLP Architecture

Layers 21–28 of Qwen2.5-1.5B have their MLP replaced with a DualMLP module: a frozen original MLP preserving general intelligence alongside a trainable copy that absorbs new knowledge. Output is blended via an alpha parameter.

2 — Layer Injection Map

Qwen2.5-1.5B has 28 transformer layers. The final 25% (layers 21–27) receive DualMLP injection. Earlier layers remain completely frozen.

Frozen (layers 0–20)
DualMLP injected (layers 21–27)
TF-IDF Gating — During TTT-E2E learning, a sparse memory gate masks gradients for general-purpose neurons (high IDF across calibration corpus). Only document-specific neurons receive full gradients, preventing catastrophic overwriting. Threshold: 0.3, calibrated on 2000 samples.
3 — Five Learning Strategies
01
TTT-E2E
Test-Time Training End-to-End

Direct weight modification via mini-batch gradient descent. Tokenizes documents into 32-token batches, runs forward+backward through DualMLP layers. TF-IDF gates protect general neurons.

Type: Weight-based
Forgetting: LOW
GPU: 24GB
02
JitRL MVP
Just-in-Time Retrieval Learning

Lightweight retrieval-augmented approach. Indexes document chunks via TF-IDF, retrieves top-3 at query time, prepends as context, and applies logit biasing toward retrieved tokens.

Learn: ~0.002s
Generate: ~2.4s
Forgetting: NONE
03
JitRL Full
Reward-Guided Logit Modulation

Documents encoded into hidden-state embeddings stored in a knowledge store. At query time, cosine similarity retrieval computes a reward signal that modulates the model's logit distribution.

Learn: ~0.04s
Generate: ~33s
Forgetting: NONE
04
ACE
Agentic Context Engineering

Zero-weight-update approach. Evolves a playbook of strategies through Generate → Reflect → Curate loops powered by Ollama. Failures become strategies, successes become rules.

Loops: 3 cycles
LLM: Ollama
Forgetting: NONE
05
Doc-to-LoRA
Hypernetwork-Generated LoRA Adapters

A Perceiver-based hypernetwork (8 cross-attention blocks) reads document activations from frozen Gemma-2-2b-it and outputs rank-8 LoRA weight matrices in a single forward pass. No gradient descent needed. Supports both doc mode (document content) and text mode (task description). Based on Sakana AI research.

Learn: <1s
LoRA Rank: 8
Chunks: 1024 tokens
Base: Gemma-2-2b-it
Forgetting: ADAPTER

When to use which? — TTT-E2E for deep, permanent knowledge internalization. JitRL MVP for fast, low-risk retrieval augmentation. JitRL Full for nuanced, embedding-based retrieval (needs tuning). ACE for iterative quality improvement without touching weights. Doc-to-LoRA for sub-second adapter generation from documents or task descriptions.
